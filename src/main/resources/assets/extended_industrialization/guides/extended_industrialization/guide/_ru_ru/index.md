# Extended Industrialization

<MarginFloatingImage src="assets/logo.png" left="0" right="10" />

Extended Industrialization — дополнение для Modern Industrialization, добавляющее разнообразные механизмы и инструменты!

Основная цель Extended Industrialization — расширить возможности Modern
Industrialization, сохраняя его принципы и назначение. Например, [мультиблоки
с пакетной обработкой](machines/batching_multiblocks.md) позволяют ещё сильнее масштабировать заводы, сократить
число настраиваемых механизмов и снизить нагрузку на систему.
